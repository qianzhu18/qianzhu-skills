# qianzhu-skills

Personal Codex skills for qianzhu / Lucien.

## Included Skills

### `qianzhu-writing-style`

A writing skill for qianzhu's personal-brand content, especially WeChat long-form articles about:

- AI tools
- open-source projects
- workflows
- trend observations
- the real growth of a young practitioner

This skill is designed to keep the writing:

- useful
- grounded
- judgment-driven
- human
- growth-oriented instead of institutional
- aware of title / cover conversion at the distribution entrance

### `wechat-cover`

A cover-generation skill for qianzhu WeChat articles. It standardizes:

- Dan Koe style black-and-white Victorian woodcut / etching cover prompts
- 16:9 horizontal cover candidates
- Gemini 3 first, `gemini-2.5-flash-image` only after stalls or failures
- Obsidian fullchain cover asset and hosted URL checks
